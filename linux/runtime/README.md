# Installed Clash SSH proxy configuration

This directory is generated by `clash-ssh-proxy-bootstrap`. Edit the source
repository or rerun the Windows manager instead of copying credentials here.

## Commands

```bash
proxy_status   # test the reverse tunnel
proxy_off      # disable proxy variables in this shell
proxy_on       # enable them again
```

New Bash login sessions enable the proxy by default. Existing sessions can run
`source ~/.bashrc`.

The reverse endpoint is loopback-only. Windows must be logged in, Clash must be
running, and the corresponding `ClashProxyTo-*` scheduled task must be running.

`sudo`, cron, systemd services, containers, and other users may not inherit the
login shell environment and must be configured separately.

Do not place SSH private keys, passwords, or application authentication caches
in this directory.
